# 图解图片

每一卦的“图解”图片放在这个目录里，文件名是两位数的卦序，例如 `03.jpg` 对应第三卦屯。目前六十四卦都有图片。

支持的格式有 `png`、`jpg`、`jpeg`、`webp` 和 `gif`。放入图片后，对应卦的“图解”一栏会自动显示它；没有图片的卦显示“待补充”。

## 来源

这些图片是 [finalhopes.com](http://www.finalhopes.com/yijing.html) 各卦页面上的扫描图。每张扫描图是一幅印刷木刻画，画的旁边印着卦名。这个网站没有说明扫描图出自哪一本书，也没有给出这些图的许可证。

网站上的扫描图大多还带有画下方的卦画和一段说明文字，说明文字在扫描图的下边缘被截断。放进这个目录之前，每张图都裁掉了这两部分，只保留木刻画和卦名。

第 15 卦谦的图旁边没有卦名，因为这个网站只提供了这一卦不带卦名的扫描图。
